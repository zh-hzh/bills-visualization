# bills-visualization · 账单可视化分析工具

双击导入微信 / 支付宝官方账单，自动分类、出图，生成一份含图表和明细的可视化报告（HTML，浏览器打开即可看）。

---

## 一、给使用的人（不想碰代码）

成品是一个单文件 EXE：**双击运行 → 弹窗多选账单 → 自动生成报告**。
不需要装 Python 和任何环境。

**在哪拿 exe**：直接向项目作者索取 `账户分析工具.exe` 成品文件（微信 / 网盘 / U 盘均可）。
本仓库只存源代码；exe 是打包产物，按约定不进 git 仓库。

### 怎么用
1. 双击 `账单分析工具.exe`
2. 弹出的窗口里**按住 Ctrl / Shift 多选**账单文件（微信 xlsx、支付宝 csv 一起选也行，自动识别）
3. 程序自动生成 `账单分析报告.html` 并打开给你看

> 报告内容：总收入 / 消费支出 / 往来转出 / 净结余 四张卡片，收入分类图、消费分类图、每日收支趋势图、每笔交易明细。

## 二、给开发者（拉源码来跑 / 改分类规则）

### 环境
- Python 3.10+（开发机用的是 3.12）
- 安装依赖：

```bash
pip install -r requirements.txt
```

### 运行
```bash
python main.py            # 弹窗多选文件（与 exe 效果完全一致）
python main.py -n         # 无窗口模式：直接扫描程序旁边的 data 目录
```

### 文件结构
| 文件 | 作用 | 要不要改 |
|------|------|---------|
| `main.py` | 主程序：解析 + 分类 + 统计 + 出图 + 生成 HTML | 一般不改 |
| `rules.py` | **分类规则配置**（收入/支出类别、关键词、转账开关） | **改这个调节分类** |
| `verify.py` | 验证脚本：用真实账单核对解析与分类结果 | 开发期用 |
| `explore_bill.py` | 探查账单文件结构（调试用） | 调试用 |

### 给不同客户换分类规则
改 `rules.py` 里的 `INCOME_RULES` / `EXPENSE_RULES` 关键词（例：新增医疗类），保存即可，不用动其他文件。

## 三、打包成 EXE（开发者专用）

```bash
pyinstaller --onefile --noconsole --name 账单分析工具 main.py
```

产物在 `dist\账单分析工具.exe`。要改分类 → 改 `rules.py` → 重新打包 → 把新 exe 发出去。

详细交付与打包操作见 Obsidian：`wiki\syntheses\2026-08-25\账单分析工具-交付打包手册.md`。

## 四、架构说明

### 数据流
```
微信账单 .xlsx ─┐                        ┌─ 收入分类图
支付宝账单 .csv ─┤ → 解析(read_*) → 分类 → ┼─ 消费分类图
                │          │             ├─ 每日收支趋势图
                └──concat──┘             └─ 交易明细表
                     │
            统一列名(来源/收支/金额/类别)
                     │
              df_full(全量) ──开关──→ df_stat(统计口径)
                     │
             build_report → 单个HTML(base64内嵌图, 离线可看)
```

### 三个文件分工
| 文件 | 职责 | 是否可改 |
|------|------|---------|
| `main.py` | 解析 + 分类 + 统计 + 出图 + 生成 HTML | 一般不改 |
| `rules.py` | 分类规则配置 + 转账开关（纯配置） | ✅ 客户间可改 |
| `verify.py` | 端到端验证（真实账单核对结果） | 开发期用 |

### 核心设计
1. **脏文件解析**：支付宝 csv 用**文本逐行找表头**，把「表头行+数据行」拼成字符串喂 `io.StringIO`，规避 pandas `header=` 行号错位与 ParserError。
2. **不对称统计口径（收入为主）**：收入侧转账归「家庭往来」**计入收入**；支出侧转账归「往来转账」**不参与消费占比**，由 `rules.py` 的 `EXPENSE_TRANSFER_AS_CONSUMPTION` 开关控制。
3. **出图**：matplotlib 转 PNG → base64 内嵌进单个 HTML，离线浏览器直接看，每张图标金额。
4. **exe**：PyInstaller `--onefile --noconsole` 打包，自带运行环境，客户端零依赖。
